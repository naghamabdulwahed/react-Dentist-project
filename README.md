Dentist Clinic Management System

A React-based web application designed to organize dental clinic operations through dedicated dashboards for administrators, doctors, and receptionists.

Technologies Used

- React – Building user interfaces.
- JavaScript – Application logic.
- React Router DOM – Navigation between pages.
- Material UI (MUI) – User interface components and styling.
- MUI Data Grid – Interactive data tables.
- Axios – Making HTTP requests.
- Formik – Form management.
- Yup – Form validation.
- React Chart.js 2 – Data visualization.
- HTML5 & CSS3 – Page structure and styling.
- Create React App – Development server and production builds.

Getting Started

To run the project locally:

1. Clone the repository:
   
   git clone https://github.com/naghamabdulwahed/react-Dentist-project.git

2. Navigate to the project directory:
   
   cd react-Dentist-project

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm start

5. Open your browser and visit:
   
   "http://localhost:3000"

Production Build

To create a production build, run:

npm run build
